# music_trends
a look at how music has changed from the blogging era (2000-2012) to the modern era driven by social media (2013-2020)

**Abstract:**

"The rise of streaming platforms, recommendation algorithms, and social media has
significantly changed how music is distributed, discovered, and consumed online.
This project investigates whether these internet-driven shifts have contributed to
the homogenization of popular music by analyzing Spotify audio feature data
from songs released between 2000 and 2020. Using statistical analysis, clustering,
Principal Component Analysis (PCA), and supervised machine learning models,
the study compares musical characteristics across the blog era (2000–2012) and
the modern streaming era (2013–2020). Results show statistically significant but
generally small differences across features such as danceability, energy, valence,
and speechiness. While classification models were able to distinguish songs
between eras above chance levels, PCA visualizations and clustering analysis
revealed substantial overlap between time periods, suggesting gradual shifts in
production trends rather than complete musical homogenization. Overall, the
findings indicate that internet-era music culture has influenced measurable audio
characteristics while still preserving meaningful stylistic diversity."

## Overview

## Dataset
