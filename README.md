# music_trends
a look at how music has changed from the blogging era (2000-2012) to the modern era driven by social media (2013-2020)

## Overview
This project analyzes how audio features of music have evolved from the blog era (2000–2012) to the modern era (2013–2020).

## Dataset
Spotify dataset with 160k tracks including audio features and release year.

## How to Run
1. Open notebook in Google Colab
2. Upload dataset (I named it "spotifysongs.csv"): https://www.kaggle.com/datasets/fcpercival/160k-spotify-songs-sorted?resource=download&select=Spotify+Data.ipynb
3. Run all cells
